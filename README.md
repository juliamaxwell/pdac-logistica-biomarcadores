# pdac-logistica-biomarcadores

# Predicción de Cáncer de Páncreas (PDAC) mediante Regresión Logística con Biomarcadores

Este repositorio contiene un notebook en Python donde se desarrolla un modelo de regresión logística para la predicción de cáncer de páncreas (PDAC) utilizando variables demográficas y biomarcadores séricos.

## Contenido del análisis
- Análisis exploratorio de datos
- Modelos logísticos univariados y multivariados
- Selección manual de variables
- Evaluación de interacción entre biomarcadores
- Diagnóstico del modelo
- Evaluación predictiva (ROC/AUC y matriz de confusión)

## Enfoque
El análisis prioriza la interpretabilidad y la plausibilidad clínica del modelo, con foco en un escenario de tamizaje, donde la sensibilidad resulta crítica.

## Tecnologías utilizadas
- Python
- pandas, numpy
- statsmodels
- scikit-learn
- matplotlib, seaborn

## Nota
Proyecto con fines académicos y de portafolio. No constituye una herramienta diagnóstica en implementación.
